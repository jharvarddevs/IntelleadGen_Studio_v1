### IntelleadGen High-Performance Architecture (HPA) Workflow

Follow these steps to ensure every component and page meets the "Elite Consultant" standard right out of the gate.

#### 1. Performance Baseline
- Use **Vite + React** for the frontend.
- Optimize all images: convert to high-res PNG for logos/icons (use CSS `brightness-0 invert` for dark backgrounds to maintain clarity).
- Target **<1s LCP** and **100 Performance Score**.

#### 2. "Elite" Aesthetic Standards
- Use **Inter** and **Outfit** typography.
- Implement **Mega Menus** as horizontal columnar layouts for "Phased" services.
- Ensure **Responsive Typography scaling**:
  - `text-5xl` and above must scale to `text-3xl` on mobile.
  - Use `break-words` and `whitespace-pre-line` for metrics (e.g., "85 Appointments\n/Month").
- Use **Glassmorphism** (`backdrop-blur-xl`) and branded scrollbars for premium feel.

#### 3. Conversion Optimization
- Lead with an **Interactive Hook** (Audit Tool, Scorecard, or ROI Calculator).
- Use **Multi-Step Forms** for all primary lead capture.
- Primary CTA buttons on dark backgrounds **must** use the `secondary` (white) variant.

#### 4. Strategic Authority
- Visualize the **Success Roadmap** (Phases 1-3).
- Highlight **Big-Value Metrics** with high visibility.
- Ensure all results include a **Viral Loop** (Share button or Copy to Clipboard).

#### 5. Verification Checklist
- [ ] Build succeeds with `npm run build`.
- [ ] Responsive Audit: No overflow on 390px width (iPhone).
- [ ] Contrast Audit: All CTAs clearly visible.
- [ ] SEO Audit: OpenGraph images and Favicons working.
